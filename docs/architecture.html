Factory Inventory Management System

A demo dashboard for factory operations: inventory, orders, spending, demand forecasting and reports. A Vue 3 single-page app talks over HTTP to a FastAPI service that serves sample data from JSON files held in memory. There is no database.

System architecture

Three layers on one machine: browser SPA, Python API, and JSON files loaded once at startup.

Tech stack

Small and dependency-light: three runtime packages on each side.

Frontend

  • Vue 3 Composition API
  • vue-router 4 (HTML5 history)
  • axios for HTTP
  • Vite 8 dev server, port 3000
  • Custom SVG charts, CSS Grid layouts
  • Homegrown i18n (en, ja)

Backend

  • Python 3.11+
  • FastAPI with uvicorn, port 8001
  • Pydantic v2 response models
  • uv for environments and runs

Data

  • 7 JSON files in server/data/
  • Loaded once into module globals
  • No database, no writes, no persistence
  • Sample year: 2025

Testing and tooling

  • pytest + FastAPI TestClient (httpx)
  • 3 backend test modules in tests/backend/
  • No frontend unit tests; Playwright MCP for browser checks
  • scripts/start.sh, stop.sh

Data flow: a filter change

What happens when someone picks a warehouse in the filter bar on the Dashboard.

  1. Filter selected FilterBar.vue writes to a shared ref in useFilters.js. The refs live at module level, so every view sees the same filter state.
  2. View reacts The view watches the filters, calls getCurrentFilters(), and maps Time Period, Location, Category and Status to month, warehouse, category and status.
  3. Request built api.js drops any value of "all", builds a query string and sends requests in parallel, e.g. /api/dashboard/summary, /api/orders, /api/inventory, /api/backlog.
  4. Filtered in memory FastAPI runs apply_filters (exact warehouse, case-insensitive category and status), then filter_by_month on order_date, expanding Q1-2025 style values to three months.
  5. Aggregated and validated Summary endpoints compute totals (inventory value, low stock, pending orders). List endpoints return through Pydantic response_models.
  6. Rendered JSON lands in refs (allOrders, inventoryItems), and computed properties derive the KPI cards, SVG charts and tables.

Notable findings

Things worth knowing before you change the code.

Missing endpoints. api.js calls /api/tasks (GET, POST, PATCH, DELETE) and /api/purchase-orders (GET, POST), but main.py defines neither. The Tasks modal and purchase-order creation will get 404s or 405s.
Unrouted view. views/Backlog.vue exists but has no route in main.js and no nav link.
Inconsistent client. Reports.vue hardcodes http://localhost:8001 and calls axios directly. Every other view goes through api.js.
Hardcoded year. Quarter filtering and the quarterly report only recognise 2025 (QUARTER_MAP and an if/elif chain).
Filters not applied everywhere. Spending, demand, backlog and report endpoints ignore the global filters, and inventory has no time dimension, so the month filter doesn't apply to it.
